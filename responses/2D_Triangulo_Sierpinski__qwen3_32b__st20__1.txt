To determine the coordinates $(x, y)$ for a given positive integer $n$, we can use a systematic approach based on binary tree structure or binary representation.

---

### **Method: Binary Tree Level Representation**

Each number $n$ corresponds to a node in a binary tree, where:

- **Level $y$** contains nodes from $2^{y-1}$ to $2^y - 1$.
- **Position $x$** within the level is the offset of $n$ from the start of the level.

---

### **Step-by-Step Algorithm**

1. **Compute the level $y$:**

   $$
   y = \lfloor \log_2(n) \rfloor + 1
   $$

   This gives the level number in the binary tree.

2. **Compute the starting number of that level:**

   $$
   \text{start} = 2^{y-1}
   $$

3. **Compute the position $x$ within the level:**

   $$
   x = n - \text{start} = n - 2^{y-1}
   $$
