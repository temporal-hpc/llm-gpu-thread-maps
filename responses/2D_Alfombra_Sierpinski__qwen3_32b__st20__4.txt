This is a custom traversal that loops around the perimeter of a 3×3 grid, starting from the bottom-left corner and moving clockwise.

### 🧠 Solution Approach

Given the data, the most straightforward and accurate implementation is to **map each `n` to its corresponding coordinate using a lookup table**. This is especially valid since the problem only provides data for `n` from 0 to 8.

For `n` values outside this range, we can either return an error or extend the pattern, but based on the provided data, we'll assume the traversal stops at `n = 8`.

---

### ✅ Final Python Implementation

```python
def get_coordinates(n):
    """
    Returns the (x, y) coordinate for a given integer n (0 <= n <= 8).
    The coordinates follow a custom traversal pattern on a 3x3 grid.
    """
    coordinates = [
        (0, 0),
        (1, 0),
        (1, 1),
        (0, 1),
        (0, 2),
        (1, 2),
        (2, 2),
        (2, 1),
        (2, 0)
    ]
    
    if 0 <= n < len(coordinates):
        return coordinates[n]
    else:
        raise ValueError("Input n is out of the predefined range [0, 8].")

# Example usage:
for i in range(9):
    print(f"n={i}: {get_coordinates(i)}")
```
