To construct a function `f(n)` that maps an integer `n` to a coordinate `(x, y)` following the observed pattern, we can break the problem into a few logical steps based on the structure of the data.

### **Pattern Analysis**

From the given data:

| n | x | y |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 1 | 0 |
| 2 | 2 | 0 |
| 3 | 0 | 1 |
| 4 | 2 | 1 |
| 5 | 0 | 2 |
| 6 | 1 | 2 |
| 7 | 2 | 2 |

We observe that:
- For every 8 consecutive values of `n`, there is a repeating "block" of coordinates.
- The pattern of `(x, y)` for each block is fixed.
- The `x` values in each block are offset by a fixed amount (`3`) for each new block.

### **Function Implementation**

The function can be implemented as follows:

```python
def f(n):
    # Determine the block index
    k = n // 8
    # Determine the position within the block
    r = n % 8
    # Lookup table for base coordinates within a block
    base_coords = [
        (0, 0), (1, 0), (2, 0),
        (0, 1), (2, 1),
        (0, 2), (1, 2), (2, 2)
    ]
    base_x, base_y = base_coords[r]
    # Compute final x with offset based on block
    x = base_x + 3 * k
    y = base_y
    return (x, y)
```

---

### **How It Works**

1. **Block Identification**:
   - The block index `k` is calculated as `n // 8`.
   - Each block contains 8 coordinates.

2. **Position in Block**:
   - The position within the block is `r = n % 8`.

3. **Coordinate Mapping**:
   - A lookup table (`base_coords`) gives the base `(x, y)` values for each position `r` in the block.
   - The actual `x` value is the base `x` plus `3 * k` (since each block shifts `x` by 3).
   - The `y` value is directly taken from the base.
