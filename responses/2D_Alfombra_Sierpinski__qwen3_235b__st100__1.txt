To solve this problem, we need to compute the Manhattan distance between two points in a recursively subdivided grid. The grid is divided into smaller blocks in a specific pattern, and each point's position is determined by its index in this hierarchical structure. 

### Approach
1. **Problem Analysis**: The grid is structured such that for a given level `k`, the grid size is \(3^{k+1} \times 3^{k+1}\). Each grid is divided into \(3 \times 3\) smaller blocks, each of which is further subdivided recursively up to level `k`. The position of any point within this grid can be determined by interpreting its index in terms of these subdivisions.
2. **Key Insight**: The index of a point can be decomposed to find its position in the grid:
   - **Block Index**: The index divided by 8 (since each block contains 8 points) gives the block number.
   - **Within-Block Position**: The remainder when divided by 8 gives the specific position within the block (using a predefined offset list).
   - **Block Coordinates**: The block number can be further decomposed into row and column indices within the grid of blocks.
3. **Position Calculation**: For each point, compute its coordinates (x, y) in the grid:
   - **x-coordinate**: \(3 \times \text{block\_row} + \text{offset\_x}\)
   - **y-coordinate**: \(3 \times \text{block\_column} + \text{offset\_y}\)
4. **Distance Calculation**: The Manhattan distance between two points (x1, y1) and (x2, y2) is \(|x1 - x2| + |y1 - y2|\).

### Solution Code
```python
power3 = [1] * 31
for exp in range(1, 31):
    power3[exp] = power3[exp-1] * 3

offsets = [(0, 0), (0, 1), (0, 2), (1, 0), (1, 2), (2, 0), (2, 1), (2, 2)]

import sys

def main():
    data = sys.stdin.read().split()
    t = int(data[0])
    index = 1
    results = []
    for _ in range(t):
        k = int(data[index])
        i_val = int(data[index+1])
        j_val = int(data[index+2])
        index += 3
        n = power3[k]
        
        blk_i = i_val // 8
        wi = i_val % 8
        br_i = blk_i // n
        bc_i = blk_i % n
        dx_i, dy_i = offsets[wi]
        x_i = 3 * br_i + dx_i
        y_i = 3 * bc_i + dy_i
        
        blk_j = j_val // 8
        wj = j_val % 8
        br_j = blk_j // n
        bc_j = blk_j % n
        dx_j, dy_j = offsets[wj]
        x_j = 3 * br_j + dx_j
        y_j = 3 * bc_j + dy_j
        
        dist = abs(x_i - x_j) + abs(y_i - y_j)
        results.append(str(dist))
    
    print("\n".join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We precompute the powers of 3 up to \(3^{30}\) to efficiently access \(3^k\) for any \(k\) (0 to 30) during processing.
2. **Offsets Handling**: The `offsets` list defines the relative positions within each \(3 \times 3\) block. Each block contains 8 points (since one cell is unused in the recursive subdivision).
3. **Reading Input**: The input is read in bulk for efficiency, especially given the constraints (up to 10,000 test cases).
4. **Processing Each Test Case**:
   - **Block Identification**: For each point, the block index is found by integer division of the point's index by 8. The within-block position is the remainder.
   - **Coordinates Calculation**: The block's row and column in the grid of blocks are derived from the block index. The actual coordinates are then computed by scaling the block indices by 3 and adding the within-block offsets.
5. **Distance Calculation**: The Manhattan distance between the two computed points is the sum of the absolute differences of their x and y coordinates.
6. **Output**: Results for all test cases are collected and printed at once for efficiency.

This approach efficiently navigates the hierarchical grid structure to compute the required distances by leveraging modular arithmetic and predefined positional offsets, ensuring optimal performance even for large inputs.
