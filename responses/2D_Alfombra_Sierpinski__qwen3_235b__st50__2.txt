To determine the position (row and column) of a cell at a given index `n` in a space-filling curve for a rectangular grid with **3 columns**, we observe the following pattern:
- The grid has 3 columns, and rows are filled in a **serpentine (back-and-forth) order**:
  - **Even-indexed rows** (0, 2, 4, ...) are filled from **left to right** (column 0 → column 2).
  - **Odd-indexed rows** (1, 3, 5, ...) are filled from **right to left** (column 2 → column 0).

### Approach
1. **Calculate the row index**:  
   The row index is determined by integer division of `n` by 3 (since each row contains 3 cells):  
   `row = n // 3`.

2. **Calculate the base column index**:  
   The remainder when `n` is divided by 3 gives the position within the row:  
   `col = n % 3`.

3. **Adjust for odd rows**:  
   - If the row index is **odd**, reverse the column index:  
     `col = 2 - col` (to convert left-to-right order to right-to-left).

### Solution Code
```python
def get_position(n):
    row = n // 3
    col = n % 3
    if row % 2 == 1:
        col = 2 - col
    return (row, col)
```

### Explanation
- **Row Calculation**:  
  Each row contains exactly 3 cells. Thus, the row index is `n // 3` (e.g., `n=3` → row 1, `n=6` → row 2).
  
- **Column Calculation**:  
  - For **even rows** (e.g., row 0, 2, 4), the column index is `n % 3` (left to right: 0, 1, 2).  
    Example: `n=7` → row `7//3 = 2` (even), column `7%3 = 1` → position `(2, 1)`.
  - For **odd rows** (e.g., row 1, 3, 5), the column index is reversed: `2 - (n % 3)` (right to left: 2, 1, 0).  
    Example: `n=4` → row `4//3 = 1` (odd), base column `4%3 = 1` → reversed to `2 - 1 = 1` → position `(1, 1)`.

This approach efficiently maps any non-negative index `n` to its corresponding (row, column) position in the grid, adhering to the serpentine traversal pattern. The solution handles all valid `n ≥ 0` with constant time complexity **O(1)**.
