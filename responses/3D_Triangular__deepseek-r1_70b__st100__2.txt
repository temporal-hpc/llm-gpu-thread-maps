To determine the coordinates \((x, y)\) on a grid based on a given index \(n\), we can follow these steps:

### Steps:
1. **Identify the Zone**:
   - If \(n = 0\): The coordinates are \((0, 0)\).
   - If \(1 \leq n \leq 3\): Determine the position within the second zone (z=1).
   - If \(n > 3\): Calculate the layer \(z\) beyond z=2.

2. **Calculate Layer for \(n > 3\)**:
   - Compute the starting index of each layer beyond z=2 using the formula: \(S_z = 4 + 6 \times (z-2)\).
   - Determine the specific layer by finding how many full layers fit before \(n\) and adjust \(z\) accordingly.

3. **Determine Position within Layer**:
   - For layers beyond z=2, compute the offset \(m\) within the current layer.
   - Use the quadratic formula to find the row \(y\) based on \(m\).
   - Calculate the column \(x\) by subtracting the number of points before row \(y\) from \(m\).

### Solution Code:
```python
import math

def compute_coordinates(n):
    if n == 0:
        return (0, 0)
    elif 1 <= n <= 3:
        m = n - 1
        if m == 0:
            return (0, 0)
        elif m == 1:
            return (0, 1)
        else:  # m == 2
            return (1, 1)
    else:
        layer_index = (n - 4) // 6
        z = 2 + layer_index
        S_z = 4 + 6 * (z - 2)
        m = n - S_z
        y = int((math.sqrt(8 * m + 1) - 1) // 2)
        points_before_y = y * (y + 1) // 2
        x = m - points_before_y
        return (x, y)

# Example usage:
n = 4
print(compute_coordinates(n))  # Output: (0, 0)

n = 10
print(compute_coordinates(n))  # Output: (0, 0)
```

### Explanation:
- **Zone Identification**: The grid is divided into zones based on the value of \(n\). Each zone corresponds to a different layer \(z\).
- **Layer Calculation**: For values of \(n\) beyond the initial zones, we determine which layer the index falls into by calculating how many complete layers fit before \(n\).
- **Position Calculation within Layer**: Using mathematical formulas, we compute the exact row and column based on the position within the identified layer.

This approach efficiently maps an index to its corresponding grid coordinates using a combination of arithmetic and geometric calculations.
