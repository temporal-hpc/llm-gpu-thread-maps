To solve this problem, we need to determine the coordinates (x, y) of a given non-negative integer `n` in a specific sequence where each thread (represented by `n`) is placed in a diagonal pattern. The sequence starts at (0, 0) and follows a pattern where each diagonal `k` contains `k + 1` elements. 

### Approach
1. **Problem Analysis**: The sequence of coordinates follows a diagonal pattern:
   - Diagonal 0: (0, 0) → 1 element
   - Diagonal 1: (0, 1), (1, 1) → 2 elements
   - Diagonal 2: (0, 2), (1, 2), (2, 2) → 3 elements
   - Diagonal 3: (0, 3), (1, 3), (2, 3), (3, 3) → 4 elements, and so on.
   
   The key observation is that the starting index of diagonal `k` is given by the triangular number \( T_k = \frac{k(k + 1)}{2} \). For any given `n`, we first determine which diagonal `k` it lies in. This is done by solving the inequality \( T_k \leq n < T_{k+1} \), which simplifies to finding \( k = \left\lfloor \frac{\sqrt{8n + 1} - 1}{2} \right\rfloor \).

2. **Algorithm Selection**:
   - **Step 1**: Compute `k` using the formula derived from the quadratic solution of the triangular number inequality.
   - **Step 2**: Calculate the starting index of diagonal `k` as \( \text{base} = \frac{k(k + 1)}{2} \).
   - **Step 3**: The x-coordinate is the offset from the start of the diagonal, i.e., \( x = n - \text{base} \).
   - **Step 4**: The y-coordinate is simply `k`.

3. **Complexity Analysis**: The operations involve basic arithmetic and a square root computation, which are constant time operations \( O(1) \). Thus, the solution is efficient with \( O(1) \) time and space complexity.

### Solution Code
```python
import math

def get_coordinates(n):
    m = 8 * n + 1
    k = (math.isqrt(m) - 1) // 2
    base = k * (k + 1) // 2
    x = n - base
    y = k
    return (x, y)
```

### Explanation
1. **Input Handling**: The function `get_coordinates` takes a non-negative integer `n` as input.
2. **Diagonal Calculation**: 
   - Compute `m = 8 * n + 1` to form the discriminant for the quadratic equation derived from the triangular number sequence.
   - Calculate `k` as the integer square root of `m` minus 1, divided by 2 (using integer division). This gives the diagonal index where `n` is located.
3. **Base Index Calculation**: 
   - The starting index of diagonal `k` is computed as `base = k * (k + 1) // 2`, which is the triangular number \( T_k \).
4. **Coordinate Determination**:
   - The x-coordinate is the difference between `n` and `base`, representing the position within the diagonal.
   - The y-coordinate is the diagonal index `k`.
5. **Output**: The function returns the tuple `(x, y)` representing the coordinates of `n` in the sequence.

This approach efficiently maps any non-negative integer `n` to its corresponding coordinates in the diagonal sequence by leveraging mathematical insights about triangular numbers and integer arithmetic. The solution is optimal with constant time and space complexity.
