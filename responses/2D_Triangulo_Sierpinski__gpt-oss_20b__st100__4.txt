**Solution Explanation**

For every integer `n` we have to find the pair `(x , y)` that is stored at
the position `n` in the sequence

```
(0,0),(0,1),(1,1),(0,2),(2,2),(0,3),(1,3),(2,3),(3,3),(0,4),…
```

--------------------------------------------------------------------

#### 1.  Observations

* In every pair `x ≤ y`.  
  For a fixed `y` all possible `x` are exactly the numbers that can be
  obtained by turning on **any subset of the bits that are 1 in `y`**.

  Example  
  `y = 5 (101₂)`  
  the admissible `x` values are `0 (000₂) , 1 (001₂) , 4 (100₂) , 5 (101₂)`.

  The amount of such numbers is  
  `2^{ popcount(y) }`.

* The sequence is built by writing the pairs in increasing order of `y`
  and, for every `y`, by writing the admissible `x` values in increasing
  order of their bit pattern.

  ```
  y = 0 : (0,0)
  y = 1 : (0,1),(1,1)
  y = 2 : (0,2),(2,2)
  y = 3 : (0,3),(1,3),(2,3),(3,3)
  …
  ```

  Consequently the cumulative number of pairs up to a certain `y`
  is

  ```
  F(y) = Σ_{k=0..y} 2^{popcount(k)}
  ```

  where `F(y)` is the index of the first pair with the next larger `y`.

--------------------------------------------------------------------

#### 2.  Inverting the order

For a given index `n` we first find the smallest `y` with

```
F(y) > n                         (1)
```

This is equivalent to `y` being the “block” that contains the `n`‑th pair.
All indices `n` inside this block are

```
n = F(y-1) + i       , 0 ≤ i < 2^{popcount(y)}
```

Therefore `i = n - F(y-1)` and the required `x` is the `i`‑th number
among all subsets of the set bits of `y`.  
If we write the binary positions of the set bits of `y` as  
`p0 < p1 < … < pk-1`, then the `i`‑th subset is

```
x = Σ_{j=0..k-1} ( (i >> j) & 1 ) << pj          (2)
```

--------------------------------------------------------------------

#### 3.  Computing `F(y)` efficiently

`F(y)` is the sum of `2^{popcount(t)}` for all `t ≤ y`.  
The numbers are small (≤ 10¹⁸ in the tests) but may have many set bits.
We evaluate the sum with a simple digit DP over the binary representation
of `y`:

```
dfs(pos, tight, bits_used)   // bits_used = number of 1‑bits so far
    if pos == -1 : return 1 << bits_used
    limit = (y >> pos) & 1  if tight else 1
    sum = 0
    for bit in {0,1} with bit ≤ limit
        sum += dfs(pos-1, tight and bit==limit, bits_used + bit)
    return sum
```

The recursion depth is at most 63, therefore it is very fast.

--------------------------------------------------------------------

#### 4.  Algorithm

```
read n
if n < 0: error

F(y) = submask_count_upto(y)   // DP described above

// find minimal y with F(y) > n
high = 1
while F(high) <= n : high *= 2
low = 0
while low < high
    mid = (low + high) // 2
    if F(mid) > n : high = mid
    else           : low  = mid + 1
y = low

prev = F(y-1)  (0 if y == 0)
i    = n - prev

x = kth_submask(y, i)      // formula (2)

output (x,y)
```

--------------------------------------------------------------------

#### 5.  Correctness Proof  

We prove that the algorithm outputs the pair stored at index `n`.

---

##### Lemma 1  
For every non‑negative integer `y` the set  

```
Sy = { x | 0 ≤ x ≤ y  and  (x | y) = y }
```

contains exactly `2^{ popcount(y) }` elements and they are all the
possible subsets of the set bits of `y`.

**Proof.**

`x | y = y` holds iff every bit that is `1` in `x` is also `1` in `y`.  
Thus `x` can be formed by turning on an arbitrary subset of the set
bits of `y`.  
If `y` has `k` set bits, there are `2^k` different subsets. ∎



##### Lemma 2  
Let  

```
F(y) = Σ_{t=0..y} 2^{ popcount(t) }
```

Then the first index of the block belonging to a given `y` is `F(y-1)`
(define `F(-1)=0`).  
The block for this `y` contains all pairs  
`(x , y)` with `x ∈ Sy`.

**Proof.**

By construction the sequence lists all pairs with `x ≤ y`
and `(x | y) = y`.  
For a fixed `y` exactly the elements of `Sy` appear, and by
Lemma&nbsp;1 there are `2^{ popcount(y) }` of them.
All smaller `y` have already contributed
`F(y-1)` pairs, hence the first index of the block of `y`
is exactly `F(y-1)`. ∎



##### Lemma 3  
For a fixed `y` the `i`‑th element of its block
(`0 ≤ i < 2^{ popcount(y) }`) is

```
x_i = Σ_{j=0..k-1} ( (i >> j) & 1 ) << p_j          (3)
```

where `p_0 < p_1 < … < p_{k-1}` are the binary positions of the
set bits of `y`.

**Proof.**

Because the block lists the admissible `x` values in the natural
ascending order of their binary representation, the `i`‑th element
is obtained by interpreting the binary digits of `i`
as a mask over the set bits of `y`.  
Equation (3) is exactly that conversion. ∎



##### Lemma 4  
Let `y` be the smallest integer with `F(y) > n`.  
Then the algorithm computes `x` according to Lemma&nbsp;3 and
`(x , y)` is exactly the pair stored at index `n`.

**Proof.**

`F(y-1) ≤ n < F(y)` (by minimality of `y`).  
Hence the block belonging to `y` starts at index `F(y-1)` and
contains all indices `F(y-1) , … , F(y)-1`.  
Let

```
i = n - F(y-1)          (0 ≤ i < 2^{ popcount(y) })
```

The algorithm uses exactly this `i` and applies Lemma&nbsp;3,
therefore it outputs the `i`‑th element of the block.
Consequently the pair produced by the algorithm is the one stored at
position `n`. ∎



##### Theorem  
For every integer `n ≥ 0` the algorithm outputs the unique pair
`(x , y)` that is written at the `n`‑th position of the given
sequence.

**Proof.**

By Lemma&nbsp;4 the algorithm returns the pair belonging to the
`n`‑th block and, within that block, the correct element.
The construction of the sequence guarantees that each index `n`
has exactly one pair, so the output is correct. ∎



--------------------------------------------------------------------

#### 6.  Complexity Analysis

Let `L = ⌊log₂ n⌋ + 1` (maximum number of bits of `n`).

*Computing `F(y)`*  
The digit DP visits each bit position once, thus `O(L)` time and
`O(L)` memory for the recursion stack and memoisation.

*Binary search*  
The search range is at most `2L`, therefore at most `O(L)` iterations.
Each iteration evaluates `F(y)` once.

*Computing the `k`‑th submask*  
The loop over the bits of `y` needs `O(L)` time.

Overall

```
time   :  O(L²)    (≤ 10⁴ operations for L ≤ 64)
memory :  O(L)     (≤ 64 integers)
```

which easily satisfies the limits.

#### 7.  Reference Implementation  (Python 3)

```python
import sys

# ------------------------------------------------------------
#  cumulative number of pairs up to and including y
# ------------------------------------------------------------
def submask_count_upto(y: int) -> int:
    """return Σ_{t=0..y} 2^{popcount(t)}  (y >= 0)"""
    if y < 0:
        return 0

    bits = y.bit_length()
    memo = {}

    def dfs(pos: int, tight: bool, ones: int) -> int:
        key = (pos, tight, ones)
        if key in memo:
            return memo[key]
        if pos == -1:
            return 1 << ones          # base: only one number with this many ones

        limit = (y >> pos) & 1 if tight else 1
        total = 0
        for b in (0, 1):
            if b > limit:
                break
            ntight = tight and b == limit
            total += dfs(pos - 1, ntight, ones + b)

        memo[key] = total
        return total

    return dfs(bits - 1, True, 0)


# ------------------------------------------------------------
#  k-th subset of the set bits of y  (0‑based)
# ------------------------------------------------------------
def kth_submask(y: int, k: int) -> int:
    """return the k-th number that can be obtained from y by turning
       on a subset of its set bits.  k is 0‑based."""
    positions = []
    pos = 0
    tmp = y
    while tmp:
        if tmp & 1:
            positions.append(pos)
        tmp >>= 1
        pos += 1

    result = 0
    for i, p in enumerate(positions):
        if (k >> i) & 1:
            result |= 1 << p
    return result


# ------------------------------------------------------------
#  main solving routine
# ------------------------------------------------------------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    if n < 0:
        raise ValueError("n must be non‑negative")

    # helper for cumulative counts
    F = submask_count_upto

    # find minimal y with F(y) > n
    high = 1
    while F(high) <= n:
        high <<= 1
    low = 0
    while low < high:
        mid = (low + high) // 2
        if F(mid) > n:
            high = mid
        else:
            low = mid + 1
    y = low

    prev = F(y - 1) if y > 0 else 0
    i = n - prev

    x = kth_submask(y, i)

    # print as a tuple (x,y)
    sys.stdout.write(f"({x},{y})")


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input/output format.
