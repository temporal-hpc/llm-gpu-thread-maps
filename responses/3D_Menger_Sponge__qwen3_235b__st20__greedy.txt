To solve this problem, we need to determine the position of a given cube in a specific sequence of cubes. The cubes are arranged in a particular order based on their coordinates (x, y, z), where each coordinate can be 0, 1, or 2. The sequence is structured such that cubes are ordered first by z-coordinate, then by y-coordinate, and finally by x-coordinate, with certain adjustments for cubes that are not present in the sequence.

### Approach
1. **Problem Analysis**: The problem involves finding the position of a given cube (x, y, z) in a predefined sequence. The sequence includes only cubes that are "present," which are defined as cubes where the (x, y) pair does not have two 1s (i.e., (1, 1) is excluded). The sequence is ordered by z-coordinate (0 first, then 1, then 2), followed by y-coordinate, and then x-coordinate.
2. **Key Insight**: The sequence can be divided into three segments based on the z-coordinate:
   - **z = 0**: Contains 8 cubes (all combinations of x and y except (1, 1)).
   - **z = 1**: Contains 4 cubes (combinations where y is not 1, i.e., (0,0), (2,0), (0,2), (2,2)).
   - **z = 2**: Contains 8 cubes (same as z = 0).
3. **Position Calculation**:
   - **Base Position**: Depending on the z-coordinate, the base position is 0 for z=0, 8 for z=1, and 12 for z=2.
   - **y-coordinate Contribution**: For z=0 or z=2, the contribution is `3 * y` minus 1 if y > 1 (to adjust for the missing (1,1) cube). For z=1, it's `2 * y` if y ≤ 1, otherwise `2 * (y - 1)`.
   - **x-coordinate Contribution**: For z=0 or z=2, if y ≠ 1, it's simply x; if y = 1, it's x if x ≤ 1, otherwise x - 1 (to skip the missing cube). For z=1, it's x if x ≤ 1, otherwise x - 1.
4. **Final Position**: The sum of the base position, y-contribution, x-contribution, and 1 (to convert from zero-based to one-based indexing).

### Solution Code
```python
def main():
    x, y, z = map(int, input().split())
    
    if z == 0:
        base = 0
    elif z == 1:
        base = 8
    else:
        base = 12
        
    if z != 1:
        count_y = 3 * y
        if y > 1:
            count_y -= 1
    else:
        if y <= 1:
            count_y = 2 * y
        else:
            count_y = 2 * (y - 1)
            
    if z != 1:
        if y != 1:
            count_x = x
        else:
            if x <= 1:
                count_x = x
            else:
                count_x = x - 1
    else:
        if x <= 1:
            count_x = x
        else:
            count_x = x - 1
            
    result = base + count_y + count_x + 1
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The coordinates (x, y, z) of the cube are read from the input.
2. **Base Position Calculation**: 
   - If `z = 0`, the base position is 0 (start of the sequence).
   - If `z = 1`, the base position is 8 (after the first 8 cubes for z=0).
   - If `z = 2`, the base position is 12 (after the first 8 cubes for z=0 and 4 cubes for z=1).
3. **y-coordinate Contribution**:
   - For `z = 0` or `z = 2`, each y-value contributes 3 positions, but if y > 1, we subtract 1 to account for the missing (1,1) cube.
   - For `z = 1`, each valid y-value (0 or 2) contributes 2 positions, so if y ≤ 1, it's `2 * y`; otherwise, it's `2 * (y - 1)`.
4. **x-coordinate Contribution**:
   - For `z = 0` or `z = 2`, if y ≠ 1, x contributes directly; if y = 1, x=2 is adjusted to x=1 (since (1,1) is missing).
   - For `z = 1`, x=2 is adjusted to x=1 (since only x=0 and x=2 are valid, but x=2 is treated as the second position).
5. **Result Calculation**: The final position is the sum of the base position, y-contribution, x-contribution, and 1 (to convert from zero-based to one-based indexing).

This approach efficiently calculates the position of any valid cube in the sequence by leveraging predefined segments and adjustments for missing cubes. The solution handles all edge cases and ensures correctness for all valid inputs.
