To solve this problem, we need to determine the coordinates (x, y) for a given integer `n` based on a specific pattern. The pattern can be broken down into blocks of 8 elements, where each block corresponds to a base value for the x-coordinate. Within each block, the offset determines the y-coordinate and the relative x-coordinate.

### Approach
1. **Block Division**: Divide the integer `n` into blocks of 8 elements. Each block corresponds to a base value for the x-coordinate, calculated as `3 * block_number`.
2. **Offset Calculation**: For each block, determine the offset within the block using `n % 8`.
3. **Determine Coordinates**: Based on the offset:
   - If the offset is less than 3, the y-coordinate is 0 and the x-coordinate is the offset.
   - If the offset is between 3 and 4 (inclusive), the y-coordinate is 1 and the x-coordinate is derived from `2 * (offset - 3)`.
   - If the offset is 5 or greater, the y-coordinate is 2 and the x-coordinate is `offset - 5`.
4. **Adjust X-Coordinate**: Add the base value of the block to the relative x-coordinate to get the final x-coordinate.

### Solution Code
```python
n = int(input())
block = n // 8
offset = n % 8

if offset < 3:
    y = 0
    x = offset
elif offset < 5:
    y = 1
    x = 2 * (offset - 3)
else:
    y = 2
    x = offset - 5

x += 3 * block
print(x, y)
```

### Explanation
- **Block Calculation**: The block number is determined by integer division of `n` by 8. This tells us which "chunk" of 8 elements we are dealing with.
- **Offset Calculation**: The remainder when `n` is divided by 8 gives the position within the block.
- **Coordinate Determination**: Depending on the offset, we determine the y-coordinate and the relative x-coordinate within the block. The relative x-coordinate is then adjusted by adding the base value of the block (which is `3 * block_number`) to get the final x-coordinate.

This approach efficiently maps each integer `n` to its corresponding coordinates by leveraging modular arithmetic and conditional checks, ensuring an optimal solution with constant time complexity.
