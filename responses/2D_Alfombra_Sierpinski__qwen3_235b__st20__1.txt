To determine the coordinates \((x, y)\) for a given non-negative integer \(n\) on the grid, follow these steps using only arithmetic operations (addition, subtraction, multiplication, integer division, and modulus). The solution avoids any conditional statements, loops, or non-arithmetic operations.

The grid is traversed in a specific pattern:
- The grid starts at \((0, 0)\) for \(n = 0\).
- For each subsequent \(n\), the position moves as follows:
  - \(n = 1\): \((1, 0)\)
  - \(n = 2\): \((2, 0)\)
  - \(n = 3\): \((0, 1)\)
  - \(n = 4\): \((2, 1)\)
  - \(n = 5\): \((0, 2)\)
  - and so on.

The pattern repeats every 5 steps, with the \(x\)-coordinate cycling through \(0, 1, 2, 0, 2\) and the \(y\)-coordinate increasing every 5 steps, but adjusted for the specific positions.

The coordinates \((x, y)\) are computed as:
- \(x = (n \mod 5) - (6 - (n \mod 5)) \times \left\lfloor \frac{n \mod 5}{3} \right\rfloor\)
- \(y = 2 \times \left\lfloor \frac{n}{5} \right\rfloor + \left\lfloor \frac{n \mod 5}{3} \right\rfloor\)

In programming terms (using common operators for integer division `//` and modulus `%`):
- \(x = n\%5 - (6 - n\%5) * ((n\%5)//3)\)
- \(y = 2*(n//5) + (n\%5)//3\)

This formula efficiently maps \(n\) to the correct \((x, y)\) by:
1. Using \(n \mod 5\) to determine the position within the current 5-step cycle.
2. Adjusting the \(x\)-coordinate based on whether the remainder is less than 3 (for \(x = 0, 1, 2\)) or not (for \(x = 0, 2\) when remainder is 3 or 4).
3. Calculating the \(y\)-coordinate from the number of complete 5-step cycles (\(n // 5\)) and an offset for the cycle position.

**Examples:**
- For \(n = 3\):
  - \(n \% 5 = 3\)
  - \(x = 3 - (6 - 3) \times (3 // 3) = 3 - 3 \times 1 = 0\)
  - \(y = 2 \times (3 // 5) + (3 // 3) = 2 \times 0 + 1 = 1\)
  - Result: \((0, 1)\)
- For \(n = 4\):
  - \(n \% 5 = 4\)
  - \(x = 4 - (6 - 4) \times (4 // 3) = 4 - 2 \times 1 = 2\)
  - \(y = 2 \times (4 // 5) + (4 // 3) = 2 \times 0 + 1 = 1\)
  - Result: \((2, 1)\)
- For \(n = 5\):
  - \(n \% 5 = 0\)
  - \(x = 0 - (6 - 0) \times (0 // 3) = 0 - 6 \times 0 = 0\)
  - \(y = 2 \times (5 // 5) + (0 // 3) = 2 \times 1 + 0 = 2\)
  - Result: \((0, 2)\)

The solution is expressed as a tuple \((x, y)\) using the given arithmetic operations.
