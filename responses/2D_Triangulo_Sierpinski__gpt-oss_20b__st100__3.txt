**Solution Explanation**

For a fixed `y` the set of all possible `x` is very easy to describe.

* Let  

```
y = b_{k-1} b_{k-2} … b_1 b_0          (binary)
```

* `x` must satisfy `0 ≤ x ≤ y`.  
  Therefore every bit that is `1` in `x` must also be `1` in `y`.  
  In other words the bits of `x` are a subset of the bits of `y`.

Consequently

```
possible x for a given y  =  { all numbers whose 1‑bits are a subset of y } .
```

The amount of such numbers is exactly  

```
2 ^ (number of 1‑bits in y)          (all subsets of the set bits of y)
```

For example  

```
y = 13  (1101₂)      → 1‑bit positions : {0,2,3}
possible x : {0,1,4,5,8,9,12,13}      ( 2³ = 8 numbers )
```

The whole infinite list of coordinates can now be seen as a sequence of
**blocks**:

```
block for y=0 : 1  number  (0,0)
block for y=1 : 2  numbers (0,1) (1,1)
block for y=2 : 2  numbers (0,2) (2,2)
block for y=3 : 4  numbers (0,3) (1,3) (2,3) (3,3)
...
```

Inside a block the numbers are sorted by `x` (lexicographic order).
If we know in which block the index `n` lies we can recover the answer.

--------------------------------------------------------------------

#### 1.  Determining the block

```
cum = 0                     # how many numbers have already been counted
y   = 0                     # current block

while True:
        f = 2 ^ popcount(y)         # how many numbers in block y
        if n < cum + f:             # n is inside this block
                offset = n - cum    # index inside the block
                break
        cum += f
        y   += 1
```

`popcount(y)` is the number of `1`‑bits in `y`.  
Python 3.8+ has `int.bit_count()` which gives this in O(1); otherwise
`bin(y).count('1')` works.

The loop stops very fast because the block size grows quickly
(`f(y)` can be as large as `2^(#1‑bits in y)`).

--------------------------------------------------------------------

#### 2.  Constructing the `x` inside the chosen block

All set‑bit positions of `y` (from low to high) are stored:

```
positions = []
t = y
while t:
        low   = t & -t                  # lowest set bit of t
        pos   = low.bit_length() - 1
        positions.append(pos)
        t ^= low                         # clear that bit
```

The `offset` (0‑based index inside the block) has a binary expansion
`offset = d_{k-1} … d_1 d_0`.  
`d_i` tells whether the *i*-th set bit of `y` participates in `x`.

```
x = 0
for i, pos in enumerate(positions):
        if (offset >> i) & 1:
                x |= 1 << pos
```

--------------------------------------------------------------------

#### 3.  Correctness Proof  

We prove that the algorithm returns the correct pair `(x , y)` for every
non‑negative integer `n`.

---

##### Lemma 1  
For a fixed `y` the set of all admissible `x` values equals

```
S(y) = { z | 0 ≤ z ≤ y  and  (z & ~y) == 0 } .
```

**Proof.**

*If* `z ∈ S(y)` then every `1`‑bit of `z` must also be `1` in `y`
(otherwise `z` would have a bit outside the range `[0,y]`), thus
`(z & ~y) == 0`.  
Conversely, if a number satisfies that condition then all its `1`‑bits
are contained in `y`; clearly `z ≤ y`. ∎



##### Lemma 2  
`|S(y)| = 2^{popcount(y)}`.

**Proof.**

`y` has `popcount(y)` set bits.
Every subset of those bits gives a different element of `S(y)`,
and there are `2^{popcount(y)}` subsets. ∎



##### Lemma 3  
Let `offset` be the index (0‑based) of a number inside block `y`.
Let `positions = [p_0 , p_1 , … , p_{k-1}]` be the set‑bit positions of `y`
in increasing order.  
Then the `x` belonging to this `offset` is

```
x = Σ_{i=0}^{k-1} ( (offset >> i) & 1 ) · 2^{p_i}
```

**Proof.**

Write `offset` in binary:  
`offset = d_{k-1} … d_1 d_0`.  
The `i`‑th binary digit `d_i` tells whether the `i`‑th set bit of `y`
participates in `x`.  
Setting the bit `p_i` of `x` exactly when `d_i = 1` gives the required
subset. ∎



##### Lemma 4  
After the first loop finishes, variables `y` and `offset` satisfy

```
0 ≤ offset < 2^{popcount(y)}        and
cum + offset = n .
```

**Proof.**

The loop increases `y` until `n < cum + 2^{popcount(y)}`.
Hence `cum ≤ n < cum + 2^{popcount(y)}` and  
`offset = n - cum` satisfies `0 ≤ offset < 2^{popcount(y)}`. ∎



##### Theorem  
For every `n ≥ 0` the algorithm returns the pair `(x , y)` that is
the `n`‑th element of the infinite sequence described in the statement.

**Proof.**

*Existence of the block.*  
By Lemma&nbsp;4 the algorithm picks the unique `y` for which the block
contains index `n`.  
The cumulative size of all previous blocks equals `cum`, therefore the
block for this `y` contains exactly `2^{popcount(y)}` consecutive
indices, starting at `cum`.  
Hence `n` is inside that block.

*Correctness of `x`.*  
For this `y` the admissible `x` are exactly the set `S(y)`
(Lemma&nbsp;1).  
Inside the block the elements of `S(y)` are listed in increasing order of
their binary masks.
Let `offset` be the position of `n` inside the block.  
By Lemma&nbsp;3 the algorithm reconstructs the subset of set bits of
`y` corresponding to this position, therefore producing the `offset`‑th
element of `S(y)`.  
Consequently the pair returned by the algorithm is precisely the
`n`‑th pair of the whole sequence.

Thus the algorithm is correct. ∎



--------------------------------------------------------------------

#### 4.  Complexity Analysis

Let `k = popcount(y)`.

```
Finding y   :  O(y)  (the loop runs once per y, but y stays small)
Computing x :  O(k)  (one pass over the set bits of y)
```

`k` is at most the number of bits of `y` (≤ 64 for 64‑bit integers),
so the algorithm is effectively constant‑time for all practical inputs
and uses only arbitrary‑size Python integers.

#### 5.  Reference Implementation  (Python 3)

```python
import sys

def popcount(x: int) -> int:
    """Return the number of 1‑bits in x."""
    # Python 3.8+ has int.bit_count()
    return x.bit_count() if hasattr(int, "bit_count") else bin(x).count("1")

def map_to_coordinates(n: int):
    """Return the (x, y) pair that is the n‑th element of the sequence."""
    if n < 0:
        raise ValueError("n must be non‑negative")

    cum = 0          # how many numbers have already been counted
    y   = 0          # current block

    # ---- find the block that contains index n ----
    while True:
        f = 1 << popcount(y)          # numbers in this block
        if n < cum + f:               # n lies inside this block
            offset = n - cum
            break
        cum += f
        y   += 1

    # ---- construct the x inside this block ----
    x = 0
    # collect set‑bit positions of y (ascending order)
    positions = []
    t = y
    while t:
        low = t & -t                 # lowest set bit
        pos = low.bit_length() - 1
        positions.append(pos)
        t ^= low

    for i, pos in enumerate(positions):
        if (offset >> i) & 1:
            x |= 1 << pos

    return x, y

# ------------------------------------------------------------------
# Example usage / simple I/O wrapper

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    x, y = map_to_coordinates(n)
    print(x, y)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input/output format.
