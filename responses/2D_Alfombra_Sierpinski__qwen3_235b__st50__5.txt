To solve this problem, we need to determine the nth point in a specific sequence of points (x, y) where each point is generated based on a mathematical pattern. The sequence starts from (0, 0) and follows a particular order where the x-coordinate cycles through 0, 1, 2 for every three points, and the y-coordinate increments every three points.

### Approach
1. **Problem Analysis**: The sequence of points is structured such that for every group of three consecutive points, the x-coordinate cycles through 0, 1, 2, and the y-coordinate remains constant within each group. After every three points, the y-coordinate increments by 1. 
2. **Key Insight**: The position `n` in the sequence can be divided into groups of three. The quotient of `n` divided by 3 gives the group number (which corresponds to the y-coordinate), and the remainder gives the position within the group (which corresponds to the x-coordinate).
3. **Algorithm Selection**: 
   - Compute `m = n // 5` (though note, the correct divisor should be 3, but the problem specifies a different pattern where every 5 points might not align; however, based on the problem examples, it's clear that the divisor is 3 for the group size. But the provided examples in the problem statement actually use a divisor of 5 for some reason. Re-examining the examples: 
     - For n=0: (0,0)
     - n=1: (1,0)
     - n=2: (2,0)
     - n=3: (0,1)
     - n=4: (2,1)  // Here, it skips 1, which is unusual.
   However, the problem states:
     - n=0: (0,0)

     - n=2: (2,0)

   But the provided solution in the problem uses:
     - m = n // 5

     - n=2: m=0, r=2 → [2, 0]
     - n=3: m=0, r=3 → [0, 1]

   This matches the problem's specified sequence. Therefore, the divisor is 5, not 3. The pattern repeats every 5 points, but the y-coordinate increments every 2 groups of 5? Actually, from the examples:

   So, every 5 points, the y-coordinate increases by 2 (since 5 points cover two y-levels: first 3 points at y=2m, next 2 points at y=2m+1).

4. **Algorithm**:
   - For a given `n`, compute `m = n // 5` (the quotient) and `r = n % 5` (the remainder).
   - If the remainder `r` is less than 3, the x-coordinate is `r` and the y-coordinate is `2 * m`.
   - If the remainder `r` is 3 or 4, the x-coordinate is 0 for `r=3` and 2 for `r=4`, and the y-coordinate is `2 * m + 1`.

### Solution Code
```python
def get_point(n):
    m = n // 5
    r = n % 5
    if r < 3:
        return [r, 2 * m]
    else:
        return [0 if r == 3 else 2, 2 * m + 1]
```

### Explanation
- **Input Handling**: The function takes an integer `n` representing the position in the sequence.
- **Group Calculation**: 
  - `m = n // 5` determines the group number. Each group consists of 5 points.
  - `r = n % 5` determines the position within the current group (0 to 4).
- **Coordinate Determination**:
  - For positions 0, 1, and 2 within a group (`r < 3`), the x-coordinate is `r` (0, 1, or 2), and the y-coordinate is `2 * m` (even levels: 0, 2, 4, etc.).
  - For positions 3 and 4 within a group (`r >= 3`), the x-coordinate is 0 if `r` is 3 and 2 if `r` is 4, and the y-coordinate is `2 * m + 1` (odd levels: 1, 3, 5, etc.).
- **Output**: The function returns a list `[x, y]` representing the coordinates of the nth point in the sequence.

This approach efficiently maps any position `n` to its corresponding point in the sequence using simple arithmetic operations, ensuring optimal performance with constant time complexity O(1).
