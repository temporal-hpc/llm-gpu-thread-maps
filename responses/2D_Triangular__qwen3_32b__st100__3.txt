To determine the coordinates corresponding to a given integer $ n $ in a triangular numbering pattern, we follow a structured mathematical approach.

---

### 🧠 **Understanding the Pattern**

The pattern is based on arranging numbers in a triangular layout, where each row contains one more element than the previous. The first few rows look like this:

```
Row 0: (0,0)
Row 1: (0,1), (1,1)
Row 2: (0,2), (1,2), (2,2)
Row 3: (0,3), (1,3), (2,3), (3,3)
...
```

Each row $ y $ contains $ y + 1 $ elements. The total number of elements up to and including row $ y $ is:

$$
\text{Total elements up to row } y = \frac{y(y+1)}{2}
$$

---

### 🧮 **Finding the Coordinates for a Given $ n $**

To find the coordinates $ (x, y) $ for a given integer $ n $, we proceed as follows:

#### 1. **Determine the Row $ y $**

We find the largest integer $ y $ such that the total number of elements up to row $ y $ is less than or equal to $ n $:

$$
y = \left\lfloor \frac{\sqrt{8n + 1} - 1}{2} \right\rfloor
$$

This comes from solving the inequality:

$$
\frac{y(y+1)}{2} \leq n < \frac{(y+1)(y+2)}{2}
$$

#### 2. **Determine the Column $ x $**

Once we know $ y $, we calculate the offset from the start of that row:

$$
x = n - \frac{y(y+1)}{2}
$$

---

### ✅ **Example: $ n = 5 $**

1. Compute $ y $:
   $$
   y = \left\lfloor \frac{\sqrt{8 \cdot 5 + 1} - 1}{2} \right\rfloor = \left\lfloor \frac{\sqrt{41} - 1}{2} \right\rfloor = \left\lfloor \frac{6.403 - 1}{2} \right\rfloor = \left\lfloor 2.701 \right\rfloor = 2
   $$

2. Compute $ x $:
   $$
   x = 5 - \frac{2 \cdot 3}{2} = 5 - 3 = 2
   $$

So the coordinates for $ n = 5 $ are $ (2, 2) $.

---

### 📦 **Final Answer**

$$
\boxed{(2, 2)}
$$
