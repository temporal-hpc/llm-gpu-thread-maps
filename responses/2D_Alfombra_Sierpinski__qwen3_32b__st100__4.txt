To determine the coordinates `(x, y)` for a given index `n` based on the observed pattern in the example `n=32` → `(6, 3)`, we can derive a systematic formula by analyzing how the indices are distributed in a 3D grid-like structure.

---

### ✅ Observed Pattern

From the example `n = 32` mapping to `(x, y) = (6, 3)`, we can infer the following:

- **x** is in the range 0–8 (3 blocks of 3 values each).
- **y** is in the range 0–2 (3 levels).
- Each **block** of 24 indices corresponds to a new `y` level.
- Each **block of 8 indices** within a `y` level corresponds to a new `x` block (0–2).

So, the pattern is:
- **x** is the position within a block of 3 values (e.g., 0–2, 3–5, 6–8).
- **y** is the level of the block, determined by the number of complete 24-index blocks.

---

### 🧠 Deriving the Formula

We can break the formula into two parts:

1. **x** is determined by:
   - First, determine the position within the 8-index sub-block: `n % 8`.
   - Then, determine the sub-block within the 24-index block: `(n // 8) % 3`.
   - Multiply by 3 to get the full x value.

2. **y** is determined by:
   - Count the number of 24-index blocks: `n // 24`.
   - Then determine the position within the 8-index sub-block: `n % 8`.
   - Divide by 3 to determine the level within the block.

So, the formula becomes:

```python
def get_coordinates(n):
    x = ((n // 8) % 3) * 3 + (n % 8)
    y = (n // 24) * 3 + (n % 8) // 3
    return (x, y)
```

- `n // 8 = 4`

- `n % 8 = 0`
- `n // 24 = 1`
- `n % 8 // 3 = 0`

So:
- `x = 1 * 3 + 0 = 3`
- `y = 1 * 3 + 0 = 3`
