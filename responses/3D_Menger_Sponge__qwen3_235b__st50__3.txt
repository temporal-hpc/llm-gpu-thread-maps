To solve this problem, we need to determine the coordinates of a robot after `n` moves, where the robot follows a specific repeating pattern every 20 moves. After every 20 moves, the entire pattern shifts by (3, 0, 0) in the x-direction. 

### Approach
1. **Pattern Recognition**: The robot's movement pattern repeats every 20 moves. For the first 20 moves (n = 0 to 19), the robot's coordinates follow a specific sequence. 
2. **Base Pattern**: We predefine the coordinates for the first 20 moves (n = 0 to 19) in a list called `base`. Each entry in this list corresponds to the (x, y, z) coordinates for a particular move within the 20-move cycle.
3. **Cycle Handling**: For any given `n`, we determine which cycle it falls into by computing `k = n // 20` (the cycle index) and `r = n % 20` (the position within the current cycle).
4. **Coordinate Calculation**: The base coordinates for position `r` in the cycle are retrieved from the `base` list. The x-coordinate is then adjusted by adding `3 * k` (since each cycle shifts the pattern by 3 units in the x-direction), while the y and z coordinates remain unchanged.

### Solution Code
```python
def robot(n):
    base = [
        (0, 0, 0), (1, 0, 0), (2, 0, 0),
        (0, 1, 0), (2, 1, 0),
        (0, 2, 0), (1, 2, 0), (2, 2, 0),
        (0, 0, 1), (2, 0, 1),
        (0, 2, 1), (2, 2, 1),
        (0, 0, 2), (1, 0, 2), (2, 0, 2),
        (0, 1, 2), (2, 1, 2),
        (0, 2, 2), (1, 2, 2), (2, 2, 2)
    ]
    k = n // 20
    r = n % 20
    x0, y0, z0 = base[r]
    x = x0 + 3 * k
    return (x, y0, z0)
```

### Explanation
1. **Base Pattern Definition**: The `base` list contains 20 tuples, each representing the (x, y, z) coordinates for moves 0 through 19. For example:
   - Move 0: (0, 0, 0)
   - Move 1: (1, 0, 0)
   - Move 3: (0, 1, 0)
   - Move 4: (2, 1, 0)
   - Move 19: (2, 2, 2)
   
2. **Cycle Calculation**: 
   - `k = n // 20` calculates how many complete 20-move cycles have been executed before the current move. Each cycle shifts the x-coordinate by 3 units.
   - `r = n % 20` finds the position within the current 20-move cycle.

3. **Coordinate Adjustment**: 
   - The base coordinates for position `r` are retrieved from the `base` list.
   - The x-coordinate is adjusted by adding `3 * k` to account for the cumulative shift from previous cycles.
   - The y and z coordinates remain as they are from the base pattern.

For example, if `n = 24`:
- `k = 24 // 20 = 1` (indicating the second cycle)
- `r = 24 % 20 = 4` (the 4th position in the cycle)
- Base coordinates at `r = 4` are (2, 1, 0)
- Adjusted x-coordinate: `2 + 3 * 1 = 5`
- Resulting coordinates: (5, 1, 0)

This approach efficiently computes the robot's position after any number of moves by leveraging the repeating pattern and incremental shifts, ensuring optimal performance even for very large values of `n`.
