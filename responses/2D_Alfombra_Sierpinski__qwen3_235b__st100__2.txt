To solve this problem, we need to compute the index of a valid cell (i, j) in a grid of R rows and C columns, where the grid is stored in row-major order but skips certain invalid cells. A cell (i, j) is invalid if and only if both (i mod 3 == 1) and (j mod 3 == 1). The solution involves calculating the index of the valid cell (i, j) without using any conditional statements.

### Approach
1. **Problem Analysis**: The grid has R rows and C columns. Each cell (i, j) is valid unless both i mod 3 equals 1 and j mod 3 equals 1. The valid cells are stored in row-major order, meaning we traverse each row from left to right before moving to the next row, skipping any invalid cells.
2. **Key Insight**: The index of a valid cell (i, j) can be derived by:
   - Calculating the total number of cells before row `i` (considering skipped invalid cells in previous rows).
   - Adding the position of cell (i, j) within its row (adjusting for skipped invalid cells in the current row if applicable).
3. **Formula Derivation**:
   - **Part 1**: `i * C` gives the total cells before row `i` if no cells were skipped.
   - **Part 2**: `((i + 1) // 3) * ((C + 1) // 3)` accounts for the number of invalid cells skipped in all previous rows (rows 0 to i-1).
   - **Part 3**: `j` is the column index within the current row.
   - **Part 4**: `((i + 2) // 3 - (i + 1) // 3) * ((j + 1) // 3)` adjusts for invalid cells skipped in the current row (only if the current row index `i` satisfies `i mod 3 == 1`).
4. **Combining Parts**: The final index is computed as `Part1 - Part2 + Part3 - Part4`.

### Solution Code
```python
def grid_index(R, C, i, j):
    part1 = i * C
    part2 = ((i + 1) // 3) * ((C + 1) // 3)
    part3 = j
    indicator = (i + 2) // 3 - (i + 1) // 3
    part4 = indicator * ((j + 1) // 3)
    return part1 - part2 + part3 - part4
```

### Explanation
1. **Part1 (`i * C`)**: This represents the total number of cells in all rows before the current row `i` if no cells were skipped.
2. **Part2 (`((i + 1) // 3) * ((C + 1) // 3)`)**: This calculates the number of invalid cells skipped in all rows before the current row. The term `(i + 1) // 3` counts how many rows before `i` have row indices congruent to 1 modulo 3 (i.e., rows 1, 4, 7, etc.). The term `(C + 1) // 3` counts how many columns in each such row are invalid (columns 1, 4, 7, etc.).
3. **Part3 (`j`)**: This is the column index within the current row.
4. **Part4 (`indicator * ((j + 1) // 3)`)**: The `indicator` is 1 if the current row `i` is congruent to 1 modulo 3 (i.e., `i mod 3 == 1`), otherwise 0. If the indicator is 1, `((j + 1) // 3)` counts how many invalid cells have been skipped before column `j` in the current row.
5. **Final Index Calculation**: The index is derived by adjusting the total cells before row `i` (Part1) by the skipped cells in previous rows (Part2), then adding the column position within the current row (Part3), and further adjusting for skipped cells in the current row (Part4).

This approach efficiently computes the index of any valid cell in the grid without using conditional statements, leveraging integer arithmetic to handle skipped cells. The solution is optimal with a constant time complexity O(1).
